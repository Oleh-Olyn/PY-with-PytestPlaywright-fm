# PY-with-PytestPlaywright-fm

## Project Description
This project contains automated end-to-end UI tests for the [Automation Exercise](https://www.automationexercise.com/) website using Python, Pytest and Playwright.
The project follows the Page Object Model (POM) approach.

The repository contains 12 automated test cases covering:
* User Registration
* User Login
* User Logout
* Registration with existing email
* Contact Us form
* Test Cases page
* Products page
* Product details
* Product search
* Subscription
* Subscription in Cart
* Adding products to Cart

The GitHub Actions pipeline automatically:
* installs Python dependencies
* installs Playwright browsers
* runs tests in Chromium and Firefox
* generates Allure test results
* builds an Allure report
* deploys the Allure report to GitHub Pages

## Requirements
Before running the project locally, make sure you have installed:
* Python 3.14
* Git
* pip

The project uses the following main tools:
* Python
* Pytest
* Playwright
* pytest-playwright
* pytest-xdist
* Allure Pytest

## Steps to Install

### 1. Clone the repository
git clone https://github.com/Oleh-Olyn/PY-with-PytestPlaywright-fm.git

### 2. Navigate to the project folder
cd PY-with-PytestPlaywright-fm

### 3. Create a virtual environment
Windows:
python -m venv .venv

Activate it:
.venv\Scripts\activate

Linux / macOS:
python3 -m venv .venv
source .venv/bin/activate

### 4. Install dependencies
pip install -r requirements.txt

### 5. Install Playwright browsers
For Chromium:
playwright install chromium

For Firefox:
playwright install firefox

Or install both:
playwright install chromium firefox

## Steps to Run Tests
### Run all tests in Chromium
pytest --browser chromium

### Run all tests in Firefox
pytest --browser firefox

### Run tests with two parallel workers
pytest -n 2 --browser chromium

### Run a specific test file
For example:
pytest tests/test_001.py --browser chromium

### Run tests and generate Allure results
Chromium:
pytest --browser chromium --alluredir=reports

Firefox:
pytest --browser firefox --alluredir=reports

## Steps to Generate Allure Report
### 1. Run tests with Allure results
pytest --browser chromium --alluredir=reports

This generates Allure results in:
reports/

### 2. Install Allure Commandline
Allure Commandline is required to generate and open the report locally.
After installing Allure, generate the report:
allure generate reports --clean -o allure-report

### 3. Open the report locally
allure open allure-report

## Allure Report
The latest Allure report generated by GitHub Actions is deployed to GitHub Pages:
https://oleh-olyn.github.io/PY-with-PytestPlaywright-fm/

## CI/CD
GitHub Actions runs the automated tests on every push and pull request to the `main` branch.
Tests are executed on:
* Chromium
* Firefox
The pipeline then combines the Allure results and publishes the generated report to GitHub Pages.
